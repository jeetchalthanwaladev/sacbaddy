SAKBADDY PORTFOLIO WORDPRESS THEME

INSTALLATION
1. In WordPress, open Appearance > Themes > Add New > Upload Theme.
2. Zip the sakbaddy-theme folder and upload the ZIP, or copy the folder to wp-content/themes.
3. Activate "Sakbaddy Portfolio".
4. Open Settings > Permalinks and click Save Changes once.

EDITING THE SITE
- Appearance > Portfolio Settings: hero/about content, education and skill lines, contact details, footer, social URLs and optional GA4 ID.
- Appearance > Menus: assign a menu to Primary navigation. For one-page sections, add Custom Links to #home, #about, #resume, #portfolio, #testimonials and #contact.
- Projects: add/edit/publish projects; set a featured image, category and project details.
- Testimonials: add/edit/publish testimonials; set a featured image, role, rating and display order.
- Media > Add New: upload images and select them in Portfolio Settings or the project/testimonial editor.
- Settings > General: update the WordPress site title and tagline.

PROJECT AND TESTIMONIAL FIELDS
Projects support title, body/description, featured image, category, project URL, GitHub URL, technologies, date and display order.
Testimonials support person name/title, testimonial body, featured image, role, rating and display order.
Existing artwork and starter examples remain visible until a published project or testimonial is created; once content is added, the CMS entries take over.

CONTACT FORM
The built-in form validates required fields and email addresses, then sends messages using WordPress wp_mail() to the configured recipient. Configure a working mail transport on the WordPress host if messages are not delivered. No third-party form plugin or API key is required.

SEO AND ANALYTICS
The theme enables WordPress title-tag support and uses semantic templates. Use one SEO plugin (Yoast SEO or Rank Math) if you need editable descriptions, canonical URLs, Open Graph fields or richer sitemap controls; avoid installing both. WordPress core provides sitemap and robots.txt behavior. GA4 is optional and only loads when a valid G-XXXXXXXXXX measurement ID is entered in Portfolio Settings.

No page builder or required plugin is included.
