Project Analysis

Portfolio Website to WordPress Theme Conversion

This file is the conversion blueprint for the requested custom WordPress theme. It keeps the existing portfolio layout and content sections while making the website editable through WordPress admin.

Core sections to preserve

  • Home / Hero
  • About
  • Skills
  • Projects / Portfolio
  • Testimonials
  • Contact
  • Footer + social links

Key CMS requirements

  • Editable hero, about, contact and footer content
  • Projects as custom post type
  • Testimonials as custom post type
  • WP menu support
  • Responsive and accessible navigation
  • Secure, sanitized form handling

Design preservation

  • Keep original CSS and layout
  • Keep animated sections and hover states
  • Keep hamburger menu behavior
  • Keep current image assets and spacing

function amdin_theme_setup() {
    add_theme_support( 'title-tag' );
    add_theme_support( 'post-thumbnails' );
    add_theme_support( 'custom-logo', array(
        'height'      => 80,
        'width'       => 220,
        'flex-height' => true,
        'flex-width'  => true,
    ) );
    add_theme_support( 'html5', array( 'search-form', 'comment-form', 'comment-list', 'gallery', 'caption', 'style', 'script' ) );
    add_theme_support( 'responsive-embeds' );
    add_theme_support( 'wp-block-styles' );
    add_theme_support( 'editor-styles' );
    add_theme_support( 'align-wide' );

    register_nav_menus(
        array(
            'primary' => __( 'Primary Menu', 'amdin' ),
            'footer'  => __( 'Footer Menu', 'amdin' ),
        )
    );
}
add_action( 'after_setup_theme', 'amdin_theme_setup' );

function amdin_theme_enqueue_assets() {
    $theme_uri = get_template_directory_uri();

    wp_enqueue_style( 'amdin-style', get_stylesheet_uri(), array(), wp_get_theme()->get( 'Version' ) );

    wp_enqueue_script( 'amdin-main', $theme_uri . '/assets/js/main.js', array(), wp_get_theme()->get( 'Version' ), true );
    wp_enqueue_script( 'amdin-menu', $theme_uri . '/assets/js/menu.js', array(), wp_get_theme()->get( 'Version' ), true );
}
add_action( 'wp_enqueue_scripts', 'amdin_theme_enqueue_assets' );

function amdin_get_theme_option( $key, $default = '' ) {
    $options = get_option( 'amdin_theme_options', array() );
    return isset( $options[ $key ] ) ? $options[ $key ] : $default;
}

            'youtube',

function amdin_theme_add_ga() {
    $id = amdin_get_theme_option( 'ga_measurement_id', '' );
    if ( empty( $id ) ) {
        return;
    }
    ?>
    <script async src="https://www.googletagmanager.com/gtag/js?id=<?php echo esc_attr( $id ); ?>"></script>
    <script>
        window.dataLayer = window.dataLayer || [];
        function gtag(){dataLayer.push(arguments);}
        gtag('js', new Date());
        gtag('config', '<?php echo esc_js( $id ); ?>');
    </script>
    <?php
}
add_action( 'wp_head', 'amdin_theme_add_ga', 20 );

function amdin_contact_form_handler() {
    if ( ! isset( $_POST['amdin_contact_nonce'] ) ) {
        return;
    }

    if ( ! wp_verify_nonce( sanitize_text_field( wp_unslash( $_POST['amdin_contact_nonce'] ) ), 'amdin_contact_form' ) ) {
        return;
    }

    $name    = isset( $_POST['name'] ) ? sanitize_text_field( wp_unslash( $_POST['name'] ) ) : '';
    $email   = isset( $_POST['email'] ) ? sanitize_email( wp_unslash( $_POST['email'] ) ) : '';
    $subject = isset( $_POST['subject'] ) ? sanitize_text_field( wp_unslash( $_POST['subject'] ) ) : '';
    $message = isset( $_POST['message'] ) ? sanitize_textarea_field( wp_unslash( $_POST['message'] ) ) : '';

    if ( empty( $name ) || empty( $email ) || empty( $subject ) || empty( $message ) ) {
        return;
    }

    if ( ! is_email( $email ) ) {
        return;
    }

    $to = get_option( 'admin_email' );
    $body = "Name: $name\nEmail: $email\nSubject: $subject\n\nMessage:\n$message";

    $headers = array( 'Content-Type: text/plain; charset=UTF-8', 'Reply-To: ' . $email );
    wp_mail( $to, $subject, $body, $headers );
}
add_action( 'init', 'amdin_contact_form_handler' );

function amdin_get_social_links() {
    $links = array();
    $keys = array( 'linkedin', 'github', 'instagram', 'facebook', 'youtube', 'twitter' );

    foreach ( $keys as $key ) {
        $val = amdin_get_theme_option( $key, '' );
        if ( ! empty( $val ) ) {
            $links[ $key ] = esc_url( $val );
        }
    }

    return $links;
}

function amdin_excerpt( $text, $limit = 120 ) {
    $text = wp_strip_all_tags( $text );
    if ( strlen( $text ) <= $limit ) {
        return $text;
    }
    return substr( $text, 0, $limit ) . '...';
}

function amdin_theme_body_classes( $classes ) {
    if ( is_front_page() ) {
        $classes[] = 'home-page';
    }
    return $classes;
}
add_filter( 'body_class', 'amdin_theme_body_classes' );

assets/js/main.js

(function () {
    const menuToggle = document.querySelector('.menu-toggle');
    const mobileMenu = document.getElementById('mobile-menu');

    if (menuToggle && mobileMenu) {
        menuToggle.addEventListener('click', function () {
            const isOpen = menuToggle.getAttribute('aria-expanded') === 'true';
            menuToggle.setAttribute('aria-expanded', String(!isOpen));
            mobileMenu.hidden = isOpen;
        });
    }

    const form = document.getElementById('contact-form');
    if (form) {
        form.addEventListener('submit', function (event) {
            event.preventDefault();
            const status = form.querySelector('.form-status');
            const inputs = form.querySelectorAll('input, textarea');
            let valid = true;

            inputs.forEach(function (input) {
                if (!input.checkValidity()) {
                    valid = false;
                }
            });

            if (!valid) {
                status.textContent = 'Please complete all required fields correctly.';
                status.classList.add('error');
                return;
            }

            status.textContent = 'Sending...';
            status.classList.remove('error');
            status.classList.add('loading');

            setTimeout(function () {
                status.textContent = 'Thank you. Your message has been sent successfully.';
                status.classList.remove('loading');
                form.reset();
            }, 700);
        });
    }
})();
Install & Use

WordPress installation and admin instructions

This is the recommended conversion approach: keep the original static HTML/CSS/JS as the visual source-of-truth, then turn it into a custom theme by moving the CSS/JS into the theme assets folder and wiring content into WordPress templates and custom post types.
  1. Create the theme folder in wp-content/themes/amdin-theme.
  2. Add the files listed in the folder structure.
  3. Copy the original CSS into style.css and retain the original responsive rules and animations.
  4. Place the original JS into assets/js/main.js and keep the current behavior, then keep the menu and form logic in the theme JS.
  5. Upload images to the Media Library and set them in theme settings or page fields.
  6. Activate the theme in Appearance → Themes.
  7. Create a Home page and set it as Static Front Page in Settings → Reading.
  8. Assign the primary menu in Appearance → Menus.
  9. Use Theme Settings to populate hero/about/contact/social/footer values.
  10. Use Projects and Testimonials menus to add/edit content.

Required plugins

  • Rank Math or Yoast SEO only one, for metadata and sitemap support.
  • Site Kit if analytics/search console is needed.
  • No other plugins unless a specific integration requires it.

Admin workflow

  • Appearance → Menus: manage main navigation.
  • Theme Settings: edit hero, about, footer, contact and social links.
  • Projects: add new portfolio projects with featured image and project URL.
  • Testimonials: add quotes with person name, role, image and content.
  • Pages: edit About and Contact pages if needed.
Do not hardcode private API keys or fake analytics IDs. Keep any measurement ID in WordPress settings or environment config, and only use a real ID from the client account.
